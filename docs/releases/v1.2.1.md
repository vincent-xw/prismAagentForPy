# PrismAgentKit v1.2.1 发版记录

- 版本：**1.2.1**（patch）
- 发布日期：2026-11-25
- 发布方式：本地 `main` 快进合并后推送；附注 tag `v1.2.1`
- 提交：`9f3c312`（上一版 `v1.2.0` = `8d74fab`）
- 影响范围：**仅 UI**，无 API 协议、数据库结构与领域模型变更

## 1. 背景

v1.2.0 引入 MCP Client 后，工具审批卡片位于「执行详情 → 工具调用」区域。实际使用中审批入口过深：用户收到"等待审批"提示后仍需跳转执行详情、在工具列表里找卡片才能处理，MCP 工具调用尤其频繁，体验割裂。

本版把审批提升到会话主界面，缩短"发现待办 → 处理"的路径。

## 2. 变更内容

### 2.1 审批内联到会话窗口

- 会话页顶部（消息列表上方、固定可见）直接展示待审批卡片：
  - 显示工具名 / 文件路径；`file_*` 类展示模式、字节数与 diff 预览，其他工具展示输入参数 JSON。
  - 提供「允许执行 / 允许写入」与「拒绝」，处理后自动刷新会话投影。
- 抽取独立组件 `ui/src/features/runs/ApprovalCard.vue`，会话页与执行详情共用同一套预览/决策逻辑，避免两处行为漂移。

### 2.2 执行详情页调整

- 移除工具调用区域的审批卡片与顶部重复提示。
- 保留一条状态提示：「有 N 个工具调用等待确认，请回到会话窗口处理」+「去会话」链接。

### 2.3 版本号

- `backend/pyproject.toml`、`backend/src/prism_agent_kit/__init__.py`、`ui/package.json`、`backend/uv.lock` 统一为 `1.2.1`。

## 3. 兼容性

- 无破坏性变更：HTTP 接口、SSE 事件契约、SQLite schema 均未变化，**无需数据迁移**。
- 升级只需更新代码并重新构建 UI（`pnpm install --frozen-lockfile && pnpm build`）；后端重启即可。

## 5. 已知问题 / 遗留

- `PATCH /mcp/servers/{id}` 当前为整体替换语义（UI 始终发送完整表单），暂不支持字段级 patch。
- MCP worker 关停仍依赖哨兵 + 任务取消；极端情况下依赖超时收敛。
- MCP 客户端目前只接入 `tools`，`resources` / `prompts` 与 Server 端不在 v1.2 范围。
