## 1. 背景

v1.2 让 Agent 能接外部 MCP 工具，但它只会"做事"，不会按用户的方法做事。V1.3 引入 **Agent Skills**：把可复用流程、领域知识与配套资料打包成 `SKILL.md`，让 Agent 按需加载并遵循；对齐 Anthropic / DSH / Pi / Codex 已经收敛的"渐进披露"形态。

## 2. 变更内容

### 2.1 技能包与发现

- 解析标准 `SKILL.md`（YAML frontmatter + 正文），校验 `name`（≤64）/`description`（≤1024）；坏包隔离，不影响其他技能与启动。
- 扫描 `references/`、`scripts/`、`assets/`；资源只读，单文件 ≤200 KB，拒绝路径逃逸与符号链接越界。
- 发现目录（同名先到先得，其余 shadowed 并写日志）：
  1. `~/.prism/skills/`（`PRISM_AGENT_KIT_PRISM_HOME` 可改）
  2. `~/.agent/skills/`
  3. `~/.agents/skills/`
  4. `PRISM_AGENT_KIT_SKILLS_PATHS` 额外目录

### 2.2 清单与工具

- 每个 Run 的 system prompt 追加 `<available_skills>` 清单（name/description/path），预算 8000 字符；超限先截 description 到 200，再按名称省略并标注。
- 新增只读 `skill` 工具：`{name, path?}` 加载正文或读取资源；返回 `<skill_content>`，结果 60k 字符截断、资源列表上限 50 条。

### 2.3 显式选择（输入框 `/`）

- 输入 `/` 弹技能菜单：实时过滤（名称优先，描述兜底）、↑↓ 移动、Enter/Tab 选中、Esc 关闭、无匹配提示；IME 组合态不误触发。
- 选中后精确删除 `/xxx`，以 `◈ 技能名 ×` 标签固定；发送携带 `skill_name`，成功后清标签，失败保留草稿与标签。
- 技能正文只对下一条消息注入一次，写入 `kind='skill_context'` 的持久消息（在用户消息之前）；后续轮次靠历史连续、不重复注入。
- 该消息在上下文裁剪中受保护；仅剩其仍超预算时返回 `CONTEXT_BUDGET_EXCEEDED`。注入正文上限 20k 字符，超限标注截断。

### 2.4 接口与数据

- 新增 `GET /skills`、`GET /skills/{name}`；`POST /sessions/{id}/runs` 支持可选 `skill_name`（未知技能 422 且不创建 Run）。
- `messages` 增加 `kind`、`runs` 增加 `skill_name`，迁移 `20261126_0006`。
- 消息列表把 `skill_context` 渲染为可折叠的「已加载技能」。

### 2.5 顺带修复

- 非生产环境放行 `/docs`、`/docs/oauth2-redirect`、`/redoc`、`/openapi.json`（业务 API 仍强制 Token；production 文档仍需鉴权）。
- 新增 PyYAML（frontmatter 多行 `description: |`）与 `types-pyyaml` 开发依赖。

## 3. 兼容性

- 数据库需要执行迁移：`cd backend && uv run alembic upgrade head`（新增两个可空/带默认值的列，不破坏既有数据）。
- 无 API 破坏性变更：新增可选字段与只读接口；`MessageView` 增加 `kind`（前端契约已同步）。
- 不需要配置技能目录即可启动；无技能时清单为空，行为与 v1.2 一致。

## 4. 升级步骤

```bash
git pull
cd backend && uv sync && uv run alembic upgrade head
cd ../ui && pnpm install --frozen-lockfile && pnpm build
```

重启后端与 UI（`./scripts/dev.sh` 会自动跑迁移）。

## 6. 已知问题 / 遗留

- `scripts/` **不执行**：V1.3 只读技能包；依赖脚本的官方文档技能（pdf/docx/xlsx/pptx）只能给出计划，不能真正跑。
- 不做技能作者化、技能市场、项目级目录（`.agent/skills`）与目录热更新。
- 技能目录有 5 秒缓存：新增/删除技能后，`GET /skills` 与清单最多延迟 5 秒刷新，期间 `get` 可能短暂失败。
- 生产环境 Swagger 仍需 Token（未关闭 docs）。
- 技能正文 >20k 字符会被截断（`skill-creator` 等大技能可见）。
