# PrismAgentKit Core UI 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 基于 Python Agent Core 交付具有全新深浅主题、首次连接引导、流式对话和按需执行详情的 Vue 工作台。

**Architecture:** 采用已确认的“对话工作台 + 按需执行详情 + 独立设置页”。HTTP DTO、SSE 传输、运行投影、会话控制与页面组件分层；Backend 是运行事实来源。先展示视觉原型，再完成基础组件、真实接口与状态恢复，最后分别验收自动化场景和实际 Core 联调。

**Tech Stack:** 现有 Vue 3、TypeScript 6.0、Vite 8、pnpm 11.9.0；新增 Tailwind CSS 4、shadcn-vue 按需组件、Vue Router、Zod、Vitest、Vue Test Utils、Playwright。使用 Vue 响应式服务共享状态，首期不引入额外状态管理框架。

**Spec:** [已确认的 Core UI 设计](../specs/2026-11-22-core-ui-design.md)。

## 全局约束（Global Constraints）

- 仅实施 `ui/` 与本次 UI 文档；不移动或修改 Python 源码、数据库迁移、根目录 Python 配置和空 `backend/`。
- 当前工作区是 `feat/python-ui-separation` 的独立 worktree，继续在这里执行，不切换或合并 Backend 分支。
- Backend 契约基线为 `feat/python-agent-core` 的 `5a8f897`；实施前重新检查提交及 DTO 差异，不修改该分支。
- Node.js 要求保持 `^22.13.0 || >=24.0.0`，pnpm 固定 `11.9.0`；依赖与 peer 范围核对后写入锁文件，不使用强制忽略冲突的安装选项。
- 首期只有会话与设置两个一级入口；MCP、Workspace、RAG、设备、多 Agent、Workflow、模型管理和会话删除/重命名等不在范围内。
- 深浅两套主题使用设计第 4 节的色板与语义；支持跟随系统，在首次绘制前应用偏好。
- 开发端口 `3000`、静态预览端口 `4173`，均监听 `127.0.0.1`，端口冲突直接报错。
- 新增必填 `VITE_API_BASE_PATH=/api/v1`；只接受以 `/` 开始、不含查询/片段的同源路径。缺失或非法时报告配置错误。
- `PRISM_UI_API_TARGET` 继续由 Vite 开发代理读取，必须是实际 Core 地址。生产 `/api/` 由部署入口代理；静态预览不冒充 Backend。
- Token 使用当前标签页的 `sessionStorage`；不放入 `VITE_`、长期 `localStorage`、URL、日志或演示数据。
- 默认不做字段兜底。必需字段缺失、错误类型与非法状态作为协议错误；契约明确允许的 `null`、空数组和对象型消息按原语义处理。
- 函数、变量及复杂逻辑添加中文注释，标识符使用英文。
- 原型明确标识演示数据；自动化夹具只在测试中拦截请求；产品请求失败不自动切换 Mock。
- 本文所有命令均使用 `rtk`。除标明仓库根目录的 Git 命令外，执行目录均为 `ui/`。

## 任务 5：Run、临时文本与工具详情投影
