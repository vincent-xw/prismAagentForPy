# Skills (V1.3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Agent 按 Agent Skills 规范使用技能包：清单常驻、`skill` 工具隐式加载、输入框 `/` 显式选择并高亮；显式技能正文只注入一次、持久留在会话历史。

**Architecture:** 磁盘技能包（`SKILL.md` + references）→ `application/skills/` 发现/解析/清单渲染 → 每 Run system prompt 追加清单；`skill` 内置工具按需加载正文/资源；显式选择通过 `RunCreate.skill_name` 在事务内写入 `kind='skill_context'` 消息（受上下文裁剪保护）。

**Tech Stack:** Python 3.12、FastAPI、SQLAlchemy 2 Async + aiosqlite、Alembic、Pydantic v2；Vue 3 + zod + Vitest。

**Spec:** `docs/superpowers/specs/2026-11-26-skills-design.md`

## Global Constraints

- 只读取文本资源；单文件 ≤ 200 KB；拒绝路径逃逸、符号链接越界；不执行 `scripts/`。
- 清单预算 `skills_catalog_max_chars` 默认 8000；`skill` 工具返回体 ≤ `skills_max_tool_result_chars` 默认 60_000，截断带 `truncated`。
- 技能名 `^[a-z0-9]+(?:-[a-z0-9]+)*$`、≤64；description ≤1024；坏包隔离，不阻断启动与其他技能。
- 根目录优先级：`~/.prism/skills` → `~/.agent/skills` → `~/.agents/skills` → `skills_paths`（逗号分隔）；同名先到先得，其余 `shadowed`。
- 显式技能只影响下一条消息；正文只写一次；`skill_context` 消息受裁剪保护；仅剩其与当前消息仍超预算时报 `CONTEXT_BUDGET_EXCEEDED`。
- 结构变更带迁移 `20261126_0006_skill_context`；前端 zod 运行时校验，不补字段。
- 质量门槛：`uv run pytest`、`ruff check`、`ruff format --check`、`mypy src`；`pnpm check`、`pnpm test`、`pnpm build`。
- 命令在 `backend/` 用 `uv run`，在 `ui/` 用 `pnpm`。

## Review Focus

1. **技能正文不被裁掉**：大历史下 `skill_context` 仍存活；只剩受保护内容超预算时明确报错（Task 7、12）。
2. **显式注入只一次且顺序正确**：`skill_context` 在 user 消息之前，后续 Run 不重复；未知技能不创建 Run（Task 6、8、12）。
3. **`/` 交互不误发送**：菜单打开时 Enter 只选中；IME 组合态不触发；过滤串精确删除（Task 10、12）。
4. **目录安全与隔离**：路径逃逸/符号链接/坏包/超大资源都被拒绝或跳过且不影响其他技能（Task 2、3、5）。
5. **清单预算**：超长清单先截描述再省略并告警，不挤爆上下文（Task 3、6）。
